# 04 配置与敏感信息

绿色部署配置为 `config/portable.json`。默认生产 `127.0.0.1:8090`，候选 `127.0.0.1:18090`，分支 `main`。

应用业务配置位于活动 release 的 `app/global_config.yml`。更新时保护 `global_config.yml`、`data/`、`logs/`、`browser_data/`、`update_backup/`。

Cookie、账号密码、AI Key、浏览器资料、数据库、截图和业务日志均为敏感数据。不要提交到 Git、上传网盘或粘贴到公开工单。需要远程访问时应另配反向代理、认证和 TLS，不要把 host 改成 `0.0.0.0` 直接暴露。
