# 01 目录与架构

- `runtime/`：Python 3.12.10、Node 24.16.0、Git 2.54.0、Playwright Chromium 147。
- `releases/<commit>/app`：指定上游提交源码；`deps`：该提交的独立依赖。
- `state/active-release.json`：当前活动提交；`process.json`：受管进程 PID。
- `staging/`：候选版本；生产槽位不会直接执行 `git pull` 或 `git clean`。
- `backups/`：切换前快照及 SHA-256 清单。
- `config/`：绿色部署参数与受保护路径。

管理器从自身文件位置推导根目录，不依赖当前工作目录。由于 Python embeddable 会忽略 `PYTHONPATH`，`scripts/run_release.py` 会显式注入活动源码与 deps。
