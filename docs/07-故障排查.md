# 07 故障排查

1. `STATUS.cmd` 查看 PID 与活动提交。
2. `VERIFY.cmd` 检查配置、运行时、活动 release 和编译。
3. 端口问题：`Get-NetTCPConnection -LocalPort 8090`。
4. 启动失败：查看 `logs/app/*.log`。
5. 更新失败：查看 `logs/maintenance/*.jsonl` 和候选日志；旧版默认继续运行或自动恢复。
6. GitHub 连接重置：管理器会重试并退回 GitHub API；若 API 也失败，等待网络恢复后重跑。
7. 计划任务：`Get-ScheduledTask -TaskName XianyuAutoReply-Portable-Update`。

不要手工删除 `state/process.json` 后直接终止不明 PID；先确认命令行和端口归属。
