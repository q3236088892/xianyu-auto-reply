# 05 自动更新与回滚

```bat
UPDATE.cmd --check-only
UPDATE.cmd
ROLLBACK.cmd
```

策略 A 流程：查询 `origin/main` → 隔离下载/检出源码 → 独立安装依赖 → compileall → 运行上游 unittest → 启动 Playwright Chromium → 在 18090 启动无 Cookie 的候选配置 → 检查 `/health` 和 `/docs` → 备份 → 停止生产 → 切换 → 在 8090 再次检查。切换后失败会自动恢复旧活动指针并重启旧版。

GitHub Git 协议不可用时，管理器退回 GitHub API 查询提交并下载该提交源码归档。活动 release 永不直接拉取。

当前上游提交的一个测试桩未接收新增参数；管理器只对该测试 lambda 应用窄范围兼容补丁，不修改应用运行逻辑。上游修复后，精确文本不匹配，补丁会自动不执行。

备份位于 `backups/<时间>/`；`manifest.json` 含 SHA-256。手工回滚依赖 `state/last-update.json`，首次安装且尚未更新时没有上一版本可回滚。
