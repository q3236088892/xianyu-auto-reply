# 03 迁移到另一台电脑

适用 Windows 10/11 x64。目标电脑不需要预装 Python、Node、Git 或 Docker。

1. 原电脑运行 `REMOVE-TASK.cmd` 和 `STOP.cmd`。
2. 完整复制 `xianyu-auto-reply-portable` 文件夹，不能只复制源码。
3. 在新路径运行 `VERIFY.cmd`、`START.cmd`、`STATUS.cmd`。
4. 打开 `/health` 与 `/docs` 验证。
5. 运行 `INSTALL-TASK.cmd` 重建含新绝对路径的计划任务。

文件夹路径可含空格。计划任务保存绝对路径，因此移动目录后必须重装。
